# Puantaj onay formu

Müşterinin puantajını telefondan kontrol edip onayladığı boş sayfa (Ofis Takip).

Sayfada hiçbir kişi bilgisi yoktur. Kişiler ve günler yalnız WhatsApp'tan gönderilen bağlantının `#` kısmında gelir; bu kısım tarayıcıdan hiçbir sunucuya gönderilmez ve hiçbir yere kaydedilmez. Cevap müşterinin kendi WhatsApp numarasından mesaj olarak ofise döner.
